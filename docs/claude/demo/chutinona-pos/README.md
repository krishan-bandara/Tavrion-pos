# චූටිනෝනා මධ්‍යම වෙළඳසැල — POS demo (standalone)

Double-click `index.html` (any browser) or `open-demo.bat` (Edge app window + silent printing).

- Works offline. Fonts: loads Noto Sans Sinhala from Google Fonts when online, otherwise uses Windows "Iskoola Pota".
- Checkout -> "Complete payment" shows the bill and prints an 80 mm receipt (shop name at top). Toggle "Auto print" in the header.
- Set the default Windows printer to the thermal printer; paper size is 80 mm (`@page size:80mm auto`).
- All data is sample data and resets on reload. This is a UI demo only (no database, no real drawer/printer driver).
